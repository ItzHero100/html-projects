# HTML Projects — Web Development Journey 🚀

This repository contains my first three web development projects, built while learning the fundamentals of **HTML5**.

The goal of these projects was to learn HTML by actually building websites instead of only following tutorials.

---

## 📚 Projects

### 01 — Resume

A simple personal resume webpage created using HTML.

**What I practiced:**
- Basic HTML document structure
- Headings and paragraphs
- Lists
- Links
- Images
- Semantic HTML

---

### 02 — Heroic Restaurant 🍽️

A multi-section restaurant website created using HTML.

**What I practiced:**
- Semantic HTML
- Navigation
- Images and links
- Lists
- Tables
- Page structure
- Multi-page navigation
- Organizing website assets

---

### 03 — Heroic Academy 🎓

A multi-page online learning platform created entirely with HTML.

The website includes course pages, mentor profiles, enrollment, sign-in, about, and terms & conditions pages.

**What I practiced:**
- Semantic HTML
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Forms
- Labels and form controls
- Different input types
- Radio buttons and checkboxes
- Select menus
- Textareas
- Tables
- Lists
- Definition lists
- Accessibility basics
- Internal navigation
- Multi-page website architecture
